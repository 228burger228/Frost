# Алекспром — Профессиональное холодильное оборудование

Официальный сайт и интерактивный e-commerce каталог профессионального холодильного оборудования «Алекспром» (Санкт-Петербург).

Разработано строго по спецификации и дизайн-системе Figma:
- [Figma: Главная (1440 × 5290)](https://www.figma.com/design/NmxT7zgFqy7KUnZFGrNNc5?node-id=4-2)
- [Figma: Страница товара (1440 × 2544)](https://www.figma.com/design/NmxT7zgFqy7KUnZFGrNNc5?node-id=4-343)

---

## 🚀 Стек технологий

- **Фреймворк:** React 19
- **Сборщик:** Vite 6
- **Стилизация:** Чистые CSS-токены (`src/styles/tokens.css` и `src/styles/alexprom.css`) по спецификации макетов Figma:
  - Основной фон: `#F5F6F1`
  - Тёмные блоки и кнопки: `#24362D` / `#243C31`
  - Лаймовый акцент: `#DDF29B`
  - Шрифты: `Manrope` (гротеск) + `IBM Plex Mono` (технические параметры)
- **Иконки:** Векторные SVG из оригинального дизайн-пакета (`public/assets/icons/`)
- **Адаптивность:** Полная поддержка от 360px до 1920px без горизонтального скролла

---

## 📦 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:3000`.

### 3. Сборка для продакшена
```bash
npm run build
```
Собранный статический бандл формируется в папку `dist/`.

## 🛡️ Безопасность и соответствие ТЗ
- Единый источник данных (`products.js`) питает каталог, страницу товара и модалку расчёта.
- Телефон валидируется маской `+7 (XXX) XXX-XX-XX`.
- Климатические и температурные показатели (`−35 °C`, `24 кг за 75 мин`) взяты строго из оригинальных паспортов и макетов.
